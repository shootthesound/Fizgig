# Fizgig v9.8.0: MiniMax H3 Turbo previews keep their steps

**MiniMax H3 previews during a run keep their Turbo steps.** With **Change the previews of the run going now** ticked (the default), a change on the Samples tab during a MiniMax H3 run sent the plain Steps box (20) to the run instead of your **Turbo preview steps**, so the Turbo LoRA rendered 20 steps: previews with artefacts that undersold the LoRA, and a banner reading "20 steps" while the box said 6. The run now gets your Turbo preview steps at your Turbo strength, as Start gives it, and Resume takes a changed Turbo steps or strength too (thanks u/monday_python on Reddit).

**To update:** run the updater as usual.
