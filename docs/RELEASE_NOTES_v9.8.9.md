# Fizgig v9.8.9: the loss watch on the Captions tab, Find duplicate pictures, and a smaller Krea 2 text cache

**The loss watch on the Captions tab.** Each caption card now shows its picture's loss-watch verdict as a small pill: stuck, suspect, learning, easy and so on, in the same colours as the per-image loss view. Hover over it to see what the verdict means and which run and epoch it comes from. The verdicts come from the run training on that folder, or the folder's last run. A new **Loss watch** filter between Sort and View shows just one group (stuck, say), each with its count; it's greyed out when no run on the folder has a loss log.

**Caption edits during a run train from the next epoch.** A caption you save on the Captions tab while a run trains on that folder is re-encoded at the next epoch, as an edit from the per-image loss view already was, and the card says so. Before, the run kept the old caption until you continued it. This works with the loss-watch ticks on or off. In the per-image loss view, **Edit on the Captions tab** opens the tab on that picture, and Save caption now closes the editor.

**Find duplicate pictures.** A new card on Image Prep, before the Look Consistency Filter, finds pictures in the training folder that are the same shot: copies, resized or re-saved versions and near-identical frames. A duplicate trains that picture twice as often, which can bake it in. Groups are set by a **How alike** slider; each group's largest picture is labelled and the others start marked, and a click marks or unmarks one. **Move marked out of the dataset** moves them, with their captions and masks, to an `excluded_duplicates` folder; nothing is deleted, and a run that trains sub-folders leaves that folder out. It runs on the CPU and ignores masks. (thanks @Murf-Code for the scan)

**Every saved LoRA carries its training recipe.** The LoRA's metadata now has the usual kohya training keys (seed, batch size, epochs and steps, scheduler, resolution and the picture sizes that trained, the base model's file name, dataset counts and repeats) and one Fizgig record: the model, rank and alpha, optimizer, learning rate and Adaptive LR range, timesteps, precision, block swap, and which training features were on. Names only: no folder paths, captions or tags. It never gets in the way of a save. (thanks @Murf-Code)

**Krea 2's text cache is about a quarter of the size.** Only a caption's real tokens are stored, and they're padded back when loaded, so training is exactly as before. A 30 MB cache file comes down to about 3 to 8 MB, and each step reads that much less from the drive. Old caches load as they are; there's no need to cache again. (thanks @Murf-Code)

**Fibo 2 no longer crashes with "mat2 is on cpu"** at Blocks Swap 12, 20, 28 or 36. Blocks whose layers differ (Fibo 2's cross-attention blocks) now each get their own transfer buffers, so all their weights reach the card. (thanks @Murf-Code)

**Smaller things** (thanks @Murf-Code): the sidebar's **TRAIN** and **AFTER** headings fold their tabs away, and remember it. A detail crop you delete stays deleted: it's never made again at Start, at any size, while its picture keeps training. **Make masks** has a **Stop** button (it asks twice, finishes the picture it's on and keeps the masks made). The mask editor saves while a run trains. Each preview in the Samples gallery shows the prompt it was made with, even after a mid-run change. The loss log writes the learning rate on every step. The console keeps your text selection while it updates. A Download's Save window opens where the last one went. Runs & outputs, opened while a run trains, scrolls to that run.

**To update:** run the updater as usual.
