Final step: Look Consistency Filter (faces)

            
Run this last, after every other prep stage: it scores the finished training
              folder. Pick three baseline pictures that nail the look you want; every picture's face is scored against
              all three and averaged (face similarity: ArcFace for people, DINOv2 for furry / anime faces - see Look match
              above), so no one photo's angle, expression or light sets the bar.
              It finds pictures that drifted off-look, the near-misses a loss curve can't see. Click pictures to mark
              them, or let Auto-Suggest flag the outliers, then move the marked ones out in one go (to an
              excluded_by_look subfolder; nothing is deleted). The scores are saved with the dataset, so low scorers
              you keep can ease in with the Training tab's "Warm up look outliers".

            

              

                
                
                
              

              
Each score is the average similarity to your 3 baselines. With
                ArcFace the same person typically lands at 30–70% (DINOv2 runs higher: 60–90%), the baselines included
                (each is scored against the other two as well as itself).

ModsTokens: 0

            
One mod per row; untick a row to leave it out. Strength: 0 off, 1 as stored.
              Copies: how many times it rides in the bundle - more pull harder, each costs its tokens. A second row

Apply

            
How the mods are applied while the picture renders - each control is a setting on the
              pack's Apply and Step Curve nodes (named in brackets), so what you find here is what you type into ComfyUI.

            

              
Numbered references is on, so the render takes the
                pack's Text Encode path: each row's Strength only. Retention, the fades, Shuffle and the Step Curve are not
                applied, because that ComfyUI graph has no Apply or Step Curve node.

              
Strength:
                
                

              
(Apply's Retention) How much of the references reaches the picture: 1.0 as
                stored, 0.4 keeps the look and frees the scene, 0 off. It multiplies every row's own strength.

              
Shuffle seed:
                

              
(Apply's Scramble seed) -1 keeps your row order; any seed shuffles the bundle
                and keeps a random half or more, so a different reference leads. Only matters with more than one entry.

                amount
                

              
(Apply's Frame curve - video mods only) How strongly a video mod's frames
                apply along its length; a still mod has one frame and ignores it.

                where
                shape
                amount
                

              
(the Step Curve node) Off: the same strength at every step. concept_at_start

About Fizgig
        

      

        
Fizgig

        
LoRA & Fine-tune Studio — by Peter Neill

        

        

        

        
 

        
By trade I'm a photographer and videographer — mostly live music, portraits, and a bit of teaching — and an
          AI tinkerer by night. I build a lot of open-source tooling for ComfyUI and Klein/Flux workflows.

        
Photography —
          shootthesound.com
Code &
          ComfyUI nodes — github.com/shootthesound

        
(Realtime-LoRA, LongLook, Angelo, mesh and a couple of dozen more — Fizgig grew out of
          that world.)

        

        
A quiet note: a lot of this got built in the small hours. The last year has been a hard one
          for our family — one of my children has been facing some serious health challenges — and honestly, losing
          myself in making and obsessing over tools like this is how I carve out a little headspace. It keeps my hands
          busy and my head somewhere steady.

        
Fizgig is free and always will be. If it's useful to you and you'd like to drop a coffee in the tip jar, it
          genuinely means a lot right now — but it's in no way an obligation. Using it and enjoying it is more than
          enough. Thank you for being here.

Log in

      

        
Fizgig's password. On a RunPod pod it's the FIZGIG_PASSWORD (or VNC_PASSWORD) set in the
          template, or, if none was set, the one printed in the pod's logs. On your own computer it's the one in
          Preferences > Web UI. No user name is needed.
